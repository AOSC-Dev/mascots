接收稿件 ​

该文档同时适用于主动投稿和我方约稿。

权利归属 ​

如无另行说明，我方将会在保留画师署名的情况下，要求买断永久版权，因此需要提供原始项目文件和成品文件。

在默认情况下，我方将会对包括原始项目在内的文件以 CC BY-SA 4.0 International 协议对外发布，若对公开原始项目文件有担忧，与我方交涉后也可仅公开成品文件，但请注意成品文件将依然按该协议对外发布。

项目文件 ​

请将以下文件以压缩包的形式发送给我们：

  • 原始项目文件
  • 成品文件

支持直接提交的项目文件 ​

考虑到我们的设备对不同格式的支持有限，因此我们支持直接提交以下原始项目文件：

  • Krita 项目文件 (.kra)
  • Adobe Photoshop PSD 项目文件 (.psd)
  • Inkscape SVG 文件 (.svg)
  • 带有多图层的 TIFF 文件 (.tif / .tiff)
  • GIMP 项目文件 (.xcf)
  • OpenToonz 项目 (.tnz)

支持提交的成品文件 ​

我们支持提交以下成品文件：

  • 便携式网络图形 (.png)
  • WebP 图形 (.webp)
  • AV1 图像文件格式 (.avif)

无法直接接收的项目文件 ​

我们主要使用 Linux 发行版，甚至有时会使用完全不支持 Windows / macOS 的设备，恕我们无法直接接收以下项目文件：

  • CLIP STUDIO PAINT / 优动漫 PAINT 项目文件 (.clip / .lip)
  • PaintTool SAI 项目文件 (.sai / .sai2)
  • openCanvas 项目文件 (.oci / .oc6)
  • FireAlpaca / MediBang Paint 项目文件 (.mdp)
  • Corel Painter RIFF 文件 (.rif / .riff)
  • Procreate 项目文件 (.procreate)
  • 画世界项目文件 (.hsj)
  • 天生会画项目文件 (.gopaint)

若使用以上软件创作，请保留原始项目文件，且根据指引将其转换或导出为 PSD 或 TIFF 文件后，一起发送给我们。若在该过程中遇到问题，也可联系我们寻求帮助。
