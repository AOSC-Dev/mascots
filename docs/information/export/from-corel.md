# 从 Corel Painter 导出

![](/images/export/painter/painter_zh.webp)

点击`檔案-另存新檔`，通过弹出的窗口选择 `Painter RIFF (*.rif;*.riff)`、`Photoshop (*.psd)` 和 `PNG (*.png)`。

![](/images/export/painter/painter_saveas.webp)

将以上文件存放在同一目录后，打包为 `.zip` 后提交：

 - Corel Painter RIFF 文件 (`.rif` / `.riff`)
 - PSD 文件 (`.psd`)
 - 成品文件 (`.png`)
