# 从天生会画导出

点击编辑页面右上角工具栏上操作图标可以呼出操作菜单:
![](/images/export/gopaint/gopaint-menu.png)

选择导出可以进入导出菜单栏。

![](/images/export/gopaint/gopaint.webp)

请按以下步骤完成导出工作：

 - 关闭`包含水印导出`
 - 导出作品：分别点击`源文件`、`PSD`、`PNG` 并保存到同一文件夹下

请提供以下文件，打包为 `.zip` 后提交：

 - 天生会画的源文件 (`.gopaint`)
 - PSD 文件 (`.psd`)
 - 成品文件 (`.png`)

来源：[天生会画中如何导出作品](https://consumer.huawei.com/cn/support/content/zh-cn16041996/)
