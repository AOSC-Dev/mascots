# 从 CLIP STUDIO PAINT / 优动漫 PAINT 导出

![](/images/export/csp/udongman.webp)

点击`文件-另存为`保存 `.clip` 文件。

点击`文件-拼合图像后导出`，选择 `.png(PNG)...` 和 `.psd(Photoshop 文档)...`。

将以上文件存放在同一目录后，打包为 `.zip` 后提交：

 - CSP 项目源文件 (`.clip`)
 - PSD 文件 (`.psd`)
 - 成品文件 (`.png`)
