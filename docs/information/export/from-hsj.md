# 从画世界 Pro 导出

![](/images/export/hsj/hsj.webp)

请点击右上角的设置按钮(即齿轮图标)，点击 `导出`，选择 `PNG`、`PSD`、`HSJ草稿` 并分别保存。其中 `HSJ草稿` 存放于 `内部存储/HuashijiePro/exportDrafts`，`PNG` 和 `PSD` 存放于 `内部存储/HuashijiePro/pictures`。

请提供以下文件，打包为 `.zip` 后提交：

 - 画世界草稿文件 (`.hsj`)
 - PSD 文件 (`.psd`)
 - 成品文件 (`.png`)
