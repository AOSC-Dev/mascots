# 从 openCanvas 7 导出

![](/images/export/oc/oc7.webp)

点击 `File-Save As...`，通过弹出的窗口选择 `openCanvas (*.oci)`、`PNG (*.png)`、`Photoshop (*.psd)`，保存在同一目录下。

![](/images/export/oc/oc7_dialog.webp)

将以上文件存放在同一目录后，打包为 `.zip` 后提交：

 - openCanvas 项目源文件 (`.oci`)
 - PSD 文件 (`.psd`)
 - 成品文件 (`.png`)
