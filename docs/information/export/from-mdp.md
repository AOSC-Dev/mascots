# 从 FireAlpaca / MediBang Paint 导出

![](/images/export/mdp/zh/mdp_zh1.webp)

点击`文件-出口`，将会弹出以下窗口：

![](/images/export/mdp/zh/mdp_zh2.webp)

取消勾选 `请在调整至如下所示的大小内保存`，取消勾选 `改变分辨率`(如有)。

之后选择 `PNG (24 位 PNG)` 和 `PSD`，与项目文件存放在同一目录。

![](/images/export/mdp/zh/mdp_zh3.webp)

若使用 FireAlpaca，则点击`文件-另存为`后，通过弹出的窗口将项目分别选择保存为 `.mdp`、`.psd`、`.png` 即可。

将以上文件存放在同一目录后，打包为 `.zip` 后提交：

 - 项目源文件 (`.mdp`)
 - PSD 文件 (`.psd`)
 - 成品文件 (`.png`)
